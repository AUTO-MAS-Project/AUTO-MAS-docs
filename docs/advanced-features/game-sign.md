# 游戏签到工具

游戏签到工具用于统一管理多个游戏社区的 Token，并按用户配置执行签到。目前支持 **森空岛、米游社、库街区、塔吉多**。工具会自动读取已绑定的游戏角色，并在签到结果中显示角色、游戏和状态。

::: warning 使用前须知

- 签到请求由 AUTO-MAS 在本地发起，Token 仅用于访问对应社区的官方接口，不会主动上传到与签到无关的第三方服务。
- Token 属于登录凭据，请勿发送给他人，也不要把 Token 写入公开日志、截图或配置仓库。
- “账密获取 Token”只在本次登录请求内使用账号和密码，不保存账号密码；请求完成或失败后会清理输入内容，不写入配置、日志或通知。
- AUTO-MAS 不提供短信验证码登录。使用账号密码或扫码获取凭据时，请确认网络环境和账号安全状态。
- 自动签到存在账号风控、接口变更和签到失败等风险，请自行评估并承担使用后果。

:::

## 基本用法

1. 打开 AUTO-MAS 的 **游戏社区签到** 工具。
2. 在顶部将 **启用签到** 设置为 **启用**。
3. 按用户分别编辑社区凭据。一个用户可以同时配置多个社区。
4. 根据需要开启 **签到后通知** 和 **启动时签到**。
5. 点击 **全部签到** 可以立即手动执行一次签到。

用户列表中的社区标签会显示已配置社区及最近一次结果。将鼠标悬停在标签上可以查看角色、游戏、状态和奖励等详情。

### 三种触发方式

- **MAS 任务调度签到**：由 MAS 调度任务触发，属于自动签到。自动签到每天每个账号只进行一次尝试，完成后当天不会重复请求。
- **启动时签到**：应用启动后按配置执行一次，通知单独发送。
- **手动签到**：点击 **全部签到** 立即执行，不受自动签到当天已执行的限制；手动签到期间如果自动签到正在运行，界面会提示稍后重试。

任务调度触发的签到结果会汇总到对应的任务完成通知中；启动时签到和手动签到会单独发送社区签到通知。未配置凭据的社区不会出现在通知中。

## 森空岛

森空岛签到会自动查询鹰角网络账号下的 **明日方舟** 和 **终末地** 角色。每个角色的签到状态会分别记录。

### 从网页获取 Token

1. 登录[森空岛网页端](https://www.skland.com/)。
2. 在同一浏览器会话中访问[鹰角网络通行证凭证接口](https://web-api.skland.com/account/info/hg)。
3. 在返回的 JSON 中找到 `data.content`，只复制该字段的值：

   ```json
   {
     "code": 0,
     "data": {
       "content": "<Token>"
     }
   }
   ```

4. 在用户编辑窗口的 **森空岛** 输入框中粘贴 Token 并保存。

不要复制外层 JSON、`content` 两侧的引号或其他字段。需要切换账号时，建议清理浏览器 Cookie 后重新登录；直接退出网页可能使原凭证失效。

### 使用账密获取 Token

1. 在用户编辑窗口的 **森空岛** 区域点击 **账密获取 Token**。
2. 在单独弹出的窗口中输入鹰角网络通行证手机号和密码。
3. 登录成功后，AUTO-MAS 会校验返回的凭据并自动保存；登录失败不会覆盖已有 Token。

账密只存在于本次请求的内存中，窗口关闭、登录成功或失败后都会清理输入内容。该功能不提供短信验证码登录。

## 米游社

米游社会自动读取账号绑定的 **原神、星穹铁道、绝区零、崩坏学园 2、崩坏 3、未定事件簿** 角色，并逐个查询签到状态。

### 推荐：扫码获取 Token

1. 在用户编辑窗口的 **米游社** 区域点击 **扫码获取 Token**。
2. 使用米游社 App 扫描二维码并确认登录。
3. 登录凭据会在确认后自动保存到当前用户。

二维码有有效期。出现“二维码已过期”或“二维码状态无效”时，点击 **重新生成二维码** 后再次扫描。扫码获取的是认证 Cookie，AUTO-MAS 不会把 Cookie 写入前端日志。

### 手动填写 Cookie

也可以在已登录米游社网页端的开发者工具中执行 `document.cookie`，将包含认证字段的 Cookie 字符串粘贴到输入框。不要粘贴网页 HTML、完整接口响应或无关 Cookie；缺少 `cookie_token`、`stoken` 等认证字段时，后续角色查询和签到可能失败。

## 库街区

库街区会自动读取绑定的 **战双帕弥什** 和 **鸣潮** 角色，并逐个执行社区签到。

### 获取 Token

库街区当前使用客户端登录凭据中的 Token。可按以下方式获取：

1. 使用库街区客户端登录目标账号。
2. 按客户端版本和系统环境，从本地登录数据中提取 Token。
3. 将 Token 粘贴到用户编辑窗口的 **库街区** 输入框并保存。

也可以参考开源项目 [Kuro_login](https://github.com/mxyooR/Kuro_login) 了解 Token 获取方式。该项目不是 AUTO-MAS 官方项目，使用前请自行审查代码、确认来源，并承担向第三方工具提供登录凭据的风险；AUTO-MAS 不会索要或接收该项目的账号密码。

如果账号没有绑定可签到角色，库街区不会生成可展示的游戏签到条目；Token 失效时会在签到结果中显示失败原因。

## 塔吉多

塔吉多会自动查询账号的游戏角色并执行社区签到。塔吉多凭据也可以携带云异环凭据，用于查询云异环时长；云异环不是独立的登录入口。

### 使用账密获取 Token

1. 在用户编辑窗口的 **塔吉多 / 云异环** 区域点击 **账密获取 Token**。
2. 在单独弹出的窗口中输入塔吉多账号或手机号和密码。
3. 登录成功后，AUTO-MAS 会校验 `accessToken`、`refreshToken` 和用户 ID，并自动保存凭据。

登录失败、返回字段不完整或触发风控时，不会返回“已保存 Token”的成功提示，也不会覆盖已有凭据。账号密码只存在于当前登录请求内，完成后会清理；该功能不提供短信验证码或未经验证的二维码登录。

### 手动填写凭据

输入框支持以下两种形式：

- 只填写 `refreshToken`；
- 填写凭据 JSON，可包含 `accessToken`、`refreshToken`、`uid`、`deviceId`、`roleName` 等字段。

如果同时配置云异环，可在 JSON 中加入 `cloudToken`、`cloudUserId` 和可选的 `cloudDeviceId`。凭据刷新后 AUTO-MAS 会在签到流程中更新保存的 Token，不需要每天重新登录。

## 结果与通知

签到结果中的常见状态如下：

| 状态 | 含义 |
| --- | --- |
| 成功 | 本次请求完成签到 |
| 已签到 | 今天已经签到过，未重复领取 |
| 失败 | 请求失败、凭据失效或角色信息不可用 |
| 风控 | 社区接口要求额外验证或暂时拒绝请求 |

通知会使用社区、游戏和角色名组合展示结果；能获取真实游戏名时优先显示游戏名。不同社区没有配置 Token 时不会生成空的 `0/0` 社区区块。

## 常见问题

### 登录失败后仍提示 Token 已保存

正常情况下，账号密码登录必须先通过上游响应和 Token 完整性校验，失败不会写入配置。如果界面提示异常，请查看脱敏后的错误信息，不要在日志中打印账号、密码、Cookie 或 Token。

### Token 过期或签到失败

先确认账号仍能在对应官方客户端或网页端正常登录，再重新获取 Token。米游社优先使用扫码重新获取；森空岛和塔吉多可重新打开各自的账密获取窗口。库街区需要重新从客户端获取 Token。

### 看不到某个游戏

签到工具只处理社区接口返回的已绑定角色。请确认当前 Token 对应的账号已绑定该游戏，并在保存凭据后重新执行一次手动签到。
