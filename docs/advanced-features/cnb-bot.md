AUTO-MAS QQ 群内部署了可以自动分析日志的机器人，具体使用方法如下：

1. 发送 `debug [你的具体问题]`，例如：`debug 为什么 MaaEnd 运行超时`。
2. 机器人会提示你上传日志包。请前往 AUTO-MAS 的 **设置 → 日志管理 → 导出专项日志包**，导出与问题对应的专项日志。
3. 上传完成后，等待机器人回复即可。
4. 如需追加日志，可直接上传到群内，机器人会自动捕获；如需补充更详细的描述，可以 `@机器人` 进行说明。
5. 如果问题顺利解决，可发送 `debug resolve` 通知机器人关闭问题单（Issue），或在 30 分钟无补充信息后由机器人自动关闭。
6. 如果问题仍未解决，可以 `@管理员` 进一步分析（误）。

发送 `debug help` 可获取更多机器人使用帮助。
