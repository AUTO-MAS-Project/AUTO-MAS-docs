# 使用Bot自助排障

AUTO-MAS QQ群内部署了可以自动分析日志的机器人，具体使用方法如下：

1. 发送`debug [你的具体问题]`

    如`debug 为什么MaaEnd运行超时`
2. 机器人会提示您上传日志包，请前往AUTO-MAS的**设置-日志管理-导出专项日志包**，导出您发生问题的对应专项日志
3. 上传完成后，等待机器人回复即可。
4. 如果您需要追加日志，可以直接上传到群内，机器人会自动捕获；更详细的描述可以@机器人进行补充
5. 如果您的问题顺利解决，可发送`debug resolve`通知机器人关闭issue，或30min无补充信息后机器人自动关闭
6. 如果您的问题没有解决，可以@管理进一步分析（误

更多机器人使用帮助可发送 `debug help`获取。
