# HSR 星穹铁道配置方法

## HSR 专项是什么

星穹铁道有两款常用的第三方脚本，各有所长：

- **三月七小助手（M7A）**：体力副本和周常跑得好。
- **StarRailAssistant（SRA）**：日常奖励领取、差分宇宙跑得好。

HSR 专项的意义就在这儿：**你不用二选一**。在一个脚本里同时挂上两款，哪个任务交给哪个，由你决定。AUTO-MAS 负责启动游戏、按顺序调用脚本、失败了重跑，以及记住周常月常这周做没做过。

**能跑的内容**（具体以你装的脚本版本为准）：

- 体力副本：拟造花萼（金）、拟造花萼（赤）、侵蚀隧洞、饰品提取
- 历战余响（每周重置）
- 日常与奖励：兑换码、邮件、委托、勋礼、每日实训等
- 周常：差分宇宙、货币战争
- 月常：三深渊（混沌回忆 / 虚构叙事 / 末日幻影）

::: warning 三深渊暂时用不了
三深渊的配置入口已经做好了，但当前版本在界面上把开关禁用了，还没经过充分测试。以你软件里的实际界面为准，**不建议依赖这个功能**。
:::

## 准备工作

开始前先完成以下准备，可以避开大部分常见问题。

1. **装好你要用的脚本**（M7A 和 SRA 至少装一个，两个都装才能混用）。
2. **每个脚本都手动打开一次，等它跑完初始化。** 这步千万别跳——脚本第一次启动才会生成配置文件，AUTO-MAS 要读这些文件才知道有哪些副本可选。跳过这步，后面副本下拉框就是空的。
3. **装好星穹铁道 PC 端**，国服官方客户端。
4. **全部加进杀软白名单**：AUTO-MAS、M7A、SRA、游戏这四个目录都要加，不然脚本会被拦下来，任务莫名失败。
5. **路径别用中文和空格**，例如 `D:\M7A`、`D:\SRA`。中文路径历来容易引发图像识别和路径解析问题。

::: warning 路径要选文件夹，不是选 exe
保存时 AUTO-MAS 会检查你选的文件夹里有没有对应的 exe，选错会直接弹窗拦下来：

| 填这个 | 文件夹里得有 |
| --- | --- |
| 三月七路径 | `March7th Assistant.exe` |
| SRA 路径 | `SRA-cli.exe` |
| 游戏路径 | `StarRail.exe` |
:::

## 创建 HSR 脚本

### 1. 新建脚本

进入 **脚本管理** → **新建脚本** → 选择 **HSR 脚本** → 确定。软件会跳到脚本配置页。

### 2. 填路径和基本信息

| 配置项 | 填什么 |
|---|---|
| **脚本名称** | 随便起个你认得出的名字，比如「主号星穹」 |
| **三月七路径** | M7A 所在**文件夹** |
| **SRA 路径** | SRA 所在**文件夹** |
| **游戏路径** | 星穹铁道所在**文件夹** |
| **游戏最大启动等待时间** | 启动游戏后等待客户端可操作的秒数，默认 60 秒，可按机器性能调大 |
| **游戏启动参数** | 留空 |

::: tip 只装了一个脚本也能用
M7A 和 SRA 填一个就行，另一个留空。留空的那个不会出现在下面的任务分配里。

改了路径之后，任务分配会按当前填了哪些路径自动重排一次，回去确认一下。
:::

### 3. 设置重试和超时

这几项决定任务的超时与重试行为，默认值适用于大多数情况，可按机器性能调整。

| 配置项 | 说明 | 默认值 |
|---|---|---|
| **失败任务最大尝试次数** | 一个任务失败后最多再试几次 | 3 |
| **日常任务超时限制（分钟）** | 日常 / 体力 / 奖励类任务最多跑多久 | 20 |
| **周常任务超时限制（分钟）** | 差分宇宙 / 货币战争最多跑多久 | 60 |
| **月常任务超时限制（分钟）** | 三深渊最多跑多久 | 60 |
| **启用低性能兼容模式** | 只影响 M7A 跑差分宇宙。M7A 差分跑得不稳就打开 | 关闭 |

### 4. 决定哪个任务交给哪个脚本

这是 HSR 专项的核心：四类任务各自选一个脚本来执行。

| 模块 | 包含什么 | 默认 |
|---|---|---|
| **体力** | 开拓力刷副本、历战余响 | SRA |
| **日常与奖励** | 兑换码、邮件、委托、勋礼、每日实训等 | SRA |
| **差分宇宙** | 差分宇宙 | SRA |
| **货币战争** | 货币战争 | SRA |

只填了一个脚本路径时，这里就只有那一个可选；两个都填了才能自由挑。

选完之后，下方会显示该脚本跑这个任务时用的具体策略。**这些策略是固定的，不用你填，用户页也不用再设一遍**：

- **差分宇宙**
  - SRA：乐园漫记 / 刷第一关 / 20 次 / 领积分奖励
  - M7A：领积分奖励 / 周期演算 / 是否开低性能兼容跟随上面的开关；球队、赐福、演算策略由 M7A 自己决定
- **货币战争**
  - SRA：标准博弈 / 最低难度 / 用 SRA 里存的第一套攻略 / 跑 2 次
  - M7A：领积分奖励 / 标准博弈 / 最低职级 / 阿格莱雅策略 / 遇到特定词条会重开

::: warning 用 SRA 跑货币战争，记得自己领奖励
SRA 跑完货币战争**不会自动领积分奖励**，得你自己进游戏领。换成 M7A 就没这问题。
:::

## 创建 HSR 用户

在 **脚本管理** 表格里点 **添加用户**，然后填基本信息：

| 字段 | 填什么 |
|---|---|
| **用户名** | 显示名称。跑货币战争时会作为「开拓者名称」写给脚本 |
| **启用** | 关掉的用户会被跳过 |
| **账号** | 手机号等登录账号，只在需要自动切号时才要填 |
| **密码** | 登录密码，同上 |
| **服务器** | 目前只有官服 |
| **剩余天数** | 还能代理几天。`-1` 是不限制，跑一次减一天，减到 0 就跳过这个用户 |
| **备注** | 随便写 |

::: warning 关于账号密码
账号密码保存在本地并自动加密，不会上传。

**没填 SRA 路径，或者没把任务交给 SRA 时，账号密码根本不会被用到**，可以留空。

另外，别把你的 `data/` 目录或脚本配置 JSON 发给别人，里面有加密后的凭据。
:::

### 这个用户要跑哪些任务

| 开关 | 说明 | 默认 |
|---|---|---|
| **体力** | 体力副本 + 历战余响 | 关闭 |
| **日常与奖励** | 兑换码、邮件、委托、勋礼、每日实训等 | 关闭 |
| **三深渊** | 每月一次，三个一起跑。当前版本界面上是禁用的 | 关闭 |
| **差分 / 货币** | 三选一：都不跑 / 差分宇宙 / 货币战争 | 关闭 |

打开开关后，下面会显示这个任务将用哪个脚本、按什么策略跑，和脚本页显示的一致，不用重复设置。

## 配置体力副本

**体力配置** 区有四个下拉框，对应四类副本。不想刷的留空就行：

| 下拉框 | 刷的是 |
|---|---|
| **拟造花萼（金）** | 角色经验 / 光锥经验 / 信用点 |
| **拟造花萼（赤）** | 行迹材料 |
| **侵蚀隧洞** | 遗器 |
| **饰品提取** | 位面饰品 |

金和赤的选择互不影响，可以同时存着。

下面还有几项：

- **刷取副本**：从上面四类里挑本次实际要刷的那一类。
- **当前生效关卡**：显示你选中的关卡，只是给你确认用的。
- **历战余响**：从脚本读出来的关卡里挑一个，不刷就留空。
- **历战余响开始日**：设成周几，到了那天本周还没刷就去刷。刷完这周就不再重复。

### 下拉框是空的？

因为这些副本选项不是 AUTO-MAS 自己编的，而是**从你的 M7A / SRA 里读出来的**——你把体力交给谁，就读谁的配置。所以空了基本是这三个原因：

1. **脚本没初始化过** → 手动打开 M7A / SRA 一次，等它跑完。这是最常见的原因。
2. **脚本路径填错了** → AUTO-MAS 找不到配置文件，回去检查路径。
3. **刚换了执行脚本**（比如体力从 SRA 换成 M7A）→ 两边的副本列表不一样，需要**重新选一次副本**。这时页面上会有黄色提示。

## 周常和月常不用你操心

这类任务 AUTO-MAS 会自己记账，**用户页不需要你手动挑「差分宇宙 1 / 差分宇宙 2」之类的东西**：

- **差分宇宙、货币战争、历战余响**：按周记录。这周做完了，之后再跑会自动跳过，下周一自动解锁。
- **三深渊**：按月记录，每月跑一次。

### 手动改进度

用户页底部的 **进度与重置** 区，可以看到历战余响、周常、三深渊各自"本周/本月做没做过"，每项都能手动 **标记完成** 或 **重置**。

两种情况用得上：你已经自己进游戏做完了，标记一下让 AUTO-MAS 别再跑；或者你想强制重跑一次，点重置。

::: tip 这几个按钮只改记录
它们只改 AUTO-MAS 自己的记账，**不会真的去驱动脚本执行任务**。
:::

## 运行与日志

配好之后，把脚本加进 [调度队列](/docs/task-scheduler) 就能自动跑了。三件事值得知道：

- **游戏可能被反复重启**：同一个用户的任务分给了两个不同脚本时，切换时会重启游戏。这是故意的，为了防止两个脚本的状态互相干扰。
- **你的 M7A / SRA 配置不会被弄坏**：AUTO-MAS 跑之前先备份，跑完自动还原。
- **失败会自动重跑**：按你设的「失败任务最大尝试次数」重试，重试前先重启游戏。

### 出问题要交哪些日志

- `debug/app.log` —— AUTO-MAS 主程序日志
- `debug/frontend.log` —— 界面日志

如果看起来是某个脚本本身的问题，再附上 M7A / SRA 自己的日志（位置见各脚本文档）。

## 常见问题

### 新建脚本时没有 HSR 这个选项

你的 AUTO-MAS 版本太老，还没有 HSR 专项，去 [下载页](/download/auto-mas) 更新。更新后重启一次软件。

### 路径怎么填都提示不对

**你可能选到了 exe 本身。这里要选的是文件夹。** 确认文件夹里直接放着对应的 exe：三月七是 `March7th Assistant.exe`、SRA 是 `SRA-cli.exe`、游戏是 `StarRail.exe`。也别选到子目录里去。

### 副本列表是空的

按顺序查：M7A / SRA 手动打开过一次了吗（最常见）→ 路径填的是脚本根目录吗 → 刚换过体力的执行脚本吗（换了要重选副本）。

### 任务状态不对，该跑的没跑 / 跑过了又跑

- 先看用户页的任务开关是不是你想的那样。
- 周常按周重置、月常按月重置，跨周跨月会自动清零。
- 在 **进度与重置** 区手动标记或重置，可以立刻纠正状态。
- 还是不对就看 `debug/app.log`，里面有脚本退出情况的记录。

### M7A 跑差分宇宙不太稳

打开脚本页的 **启用低性能兼容模式**。另外球队、赐福、演算策略这些 AUTO-MAS 管不到，得你提前在 M7A 里配好。

### SRA 跑完货币战争没积分

已知行为，SRA 不会自动领，自己进游戏领一下。想省这一步就把货币战争改交给 M7A。

### 游戏被反复重启

同一个用户的任务分给了两个不同脚本，切换时就会重启游戏，这是故意的，防止状态互相干扰。嫌烦就把任务都交给同一个脚本。

### 任务失败了，但日志里没有脚本的输出

说明脚本压根没跑起来，基本是被杀软拦了。把 M7A、SRA、游戏三个目录都加进杀软信任区再试。也顺便确认路径里没有中文、空格或符号链接。
