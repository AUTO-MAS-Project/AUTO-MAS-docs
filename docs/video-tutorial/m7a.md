## 0. 名词速查

| 名词 | 含义 |
| --- | --- |
| **AUTO-MAS（MAS）** | 脚本管理 / 调度平台，本教程的操作主体，负责管理脚本、用户（游戏账号）、调度执行、日志与历史记录 |
| **M7A / 三月七小助手** | March7thAssistant，星穹铁道自动化脚本本体；真正「打游戏」的程序 |
| **SRA** | 另一款星铁道自动化工具（`SRA-cli.exe`），HSR 脚本类型同样支持；视频中没有使用，路径留空 |
| **HSR 脚本** | AUTO-MAS 中「三月七 / SRA 双脚本适配」的专项脚本类型 |
| **用户** | 挂在脚本下的一个游戏账号（可多个），每个用户有自己的运行模式与配置 |
| **MAS 管控** | 运行模式之一：账号、体力副本、任务开关等全部交给 AUTO-MAS 管理 |
| **脚本直控** | 运行模式之一：脚本行为由 M7A 自己的 `config.yaml` 决定，AUTO-MAS 只负责启动游戏、跟踪/停止脚本进程和最终清理 |
| **自动代理** | 调度中心的执行模式，自动依次执行所选脚本下的所有启用用户 |
| **用户快照** | 从 M7A 的 `config.yaml` 一键导入的用户配置副本（含导入时间戳） |

开始之前，请确认以下两点（视频中演示者机器上的对应目录结构如下）：

1. **三月七小助手（M7A）已解压/安装完整**，目录中至少包含：

   ![M7A 安装目录内容](/docs/img/video-tutorial/10-M7A安装目录内容.jpg)

   本视频使用的目录：`C:\Users\Administrator\Desktop\March7thAssistant_full`。

## 2. 第一步：新建 HSR 脚本

### 2.1 打开「脚本管理」

启动 AUTO-MAS，点击左侧导航栏的 **脚本管理**。页面中每个卡片是一个脚本（含类型徽标 MAA / M9A / General / HSR 等），卡片右上角提供 **编辑脚本**、**添加用户**、**更多** 等按钮；页面右上角有 **一键收起 / 一键展开 / ＋新建脚本**。

![脚本管理页](/docs/img/video-tutorial/01-脚本管理页.jpg)

### 2.2 选择脚本类型

点击右上角 **＋ 新建脚本**，弹出「新建脚本」对话框，分为两级：

- **通用脚本**：适用于具备日志文件的自动化脚本（通过 `interface.json` 对接，视频里既有的 `March7thAssistant (General)` 就是这种接法）；
- **专项适配**：MAA 脚本（明日方舟）、SRC 脚本（星穹铁道多账号代理）、MaaEnd 脚本（MaaFramework）、M9A 脚本（重返未来：1999）、ok-ww 脚本、ok-nte 脚本（异环）、**HSR 脚本（三月七 / SRA 双脚本适配）**。

本教程演示的是 **HSR 脚本**：点选 **HSR 脚本（三月七 / SRA 双脚本适配）** 卡片（选中后卡片高亮、单选点亮），然后点击右下角 **创建并配置**。

![新建脚本-选择脚本类型](/docs/img/video-tutorial/02-新建脚本-选择脚本类型.jpg)

> 视频中演示者先点了 MAA 脚本，随后改选 HSR 脚本再点击「创建并配置」——以实际需要的类型为准即可。

### 2.3 进入配置页

创建后自动跳转到 **编辑 HSR 脚本** 页面（面包屑：`脚本管理 / 编辑 HSR 脚本`，右上角有 **← 返回**）。页面标题为 **HSR 脚本配置**，右侧带紫色徽标 `HSR (三月七 / SRA)`；顶部有一条黄色警告：

> ⚠ **请至少配置一个已加载的 HSR 引擎路径**

意思就是：下面的「三月七路径 / SRA 路径 / 游戏路径」至少要填一个（通常三月七 + 游戏）。

![HSR 脚本配置页-顶部](/docs/img/video-tutorial/03-HSR脚本配置页-顶部.jpg)

## 3. 第二步：HSR 脚本配置页详解

### 3.1 基本信息

| 字段 | 视频取值 | 说明 |
| --- | --- | --- |
| 脚本名称 | `新 HSR 脚本`（默认名，稍后重命名） | 显示在脚本管理列表与调度中心选择器中，可随时修改 |

### 3.2 运行模式提示（重要）

页面中有一条蓝色提示，决定了「脚本页」和「用户页」的分工：

> ℹ **运行模式与任务配置已移至用户配置**
> 请在用户页选择"MAS 管控"或"脚本直控"。是否由 MAS 启动、关闭、重启和监测游戏由下方开关决定；脚本页继续维护安装路径与公共执行参数。

也就是说：**脚本页 = 装在哪儿、怎么启动游戏**；**用户页 = 账号怎么跑、跑什么任务**。

### 3.3 脚本与游戏配置

小节说明原文：*填写对应脚本路径即启用该引擎；清空路径后，该引擎不再校验或参与调度。*

| 字段 | 视频取值 | 说明 |
| --- | --- | --- |
| MAS 管理游戏 | `是` | 下拉框（是 / 否）。选「是」= 由 MAS 启动、关闭、重启和监测游戏；选「否」= 不由 MAS 管理游戏进程。视频开头先试了「否」，最终配置回「是」（见 [10. 时间轴](#10-视频时间轴对照表)） |
| **三月七路径** | `C:\Users\Administrator\Desktop\March7thAssistant_full` | 点右侧 **选择文件夹**，选择 **含 `March7th Assistant.exe`** 的 M7A 安装目录 |
| SRA 路径 | （留空） | 若使用 SRA 则选择含 `SRA-cli.exe` 的目录；不用 SRA 可不填 |
| **游戏路径** | `D:\Star Rail Game` | 选择 **含 `StarRail.exe`** 的星穹铁道安装目录 |
| 游戏最大启动等待时间 | `60` 秒 | MAS 启动游戏后最多等待该时间，每 5 秒检查一次进程（见运行日志） |
| 游戏启动参数 | （留空） | 传给游戏本体的启动参数 |
| 运行时设为 1920×1080 窗口模式 | 开（蓝色） | 附注：*结束后恢复原注册表值*。MAS 会在启动游戏前把分辨率/窗口模式写为 1920×1080，任务结束后还原 |
| 兑换码仅在变化时执行 | 开（蓝色） | 附注：*新用户先执行一次*。兑换码内容没变化时不重复执行 |

**操作演示 —— 选择三月七路径：**

点击「三月七路径」右侧的 **选择文件夹**，在系统文件夹选择对话框中定位到 M7A 安装目录（视频里先在 D 盘浏览了一圈，最后从 `C:\Users\Administrator → 桌面` 进入 `March7thAssistant_full`），点击 **选择文件夹** 确认：

![选择三月七路径-文件对话框](/docs/img/video-tutorial/04-选择三月七路径-文件对话框.jpg)

确认后输入框回填完整路径，页面顶部弹出绿色提示 **✅ 路径已选择**：

![三月七路径已选择](/docs/img/video-tutorial/05-三月七路径已选择.jpg)

**操作演示 —— 选择游戏路径：**

同样点击「游戏路径」右侧 **选择文件夹**，定位到游戏安装目录 `D:\Star Rail Game`（对话框地址栏：`此电脑 > 本地磁盘 (D:) > Star Rail Game`），点击 **选择文件夹**：

![选择游戏路径-文件对话框](/docs/img/video-tutorial/06-选择游戏路径-文件对话框.jpg)

### 3.4 执行限制

| 字段 | 视频取值 | 说明 |
| --- | --- | --- |
| 失败任务最大尝试次数 | `3` | 任务失败后的重试上限 |
| 日常任务超时限制（分钟） | `20` | 单个用户日常任务的最长执行时间 |
| 周常任务超时限制（分钟） | `60` | 单个用户周常任务的最长执行时间 |
| 启用低性能兼容模式 | 关 | 附注原文：*仅对三月七差分宇宙生效，映射到 `weekly_divergent_stable_mode`* |

### 3.5 配置完成的样子

全部填好后页面如下（此时 MAS 管理游戏已改回 **是**，两个路径均已填，1920×1080 窗口模式已开启）：

![HSR 脚本配置完成](/docs/img/video-tutorial/07-HSR脚本配置完成.jpg)

确认无误后，点击右上角 **← 返回** 回到脚本管理（配置自动保存）。

> 📌 顺带一提：视频里还短暂打开过既有的 `March7thAssistant (General)` 通用脚本配置页做对比——那是 M7A 的另一种接法（通用脚本 + `interface.json`）。本教程采用 **HSR 专项适配**，无需手工填 `interface.json` 等字段。

## 4. 第三步：添加用户（脚本直控）并导入 M7A 配置

回到 **脚本管理**，在 **新 HSR 脚本** 卡片上点击 **添加用户**，进入 **编辑 HSR 用户** 页（面包屑：`脚本管理 / 新 HSR 脚本 / 编辑 HSR 用户`）。

### 4.1 基本信息

| 字段 | 视频取值 | 说明 |
| --- | --- | --- |
| 用户名 | `新用户`（默认，后改名） | 一个用户 ≈ 一个游戏账号 |
| 启用 | 开 | 关闭后该用户不参与调度 |
| 服务器 | `官服` | 下拉选择 |
| 剩余天数 | `-1` | 卡片上显示「剩余天数：无期限」的来源；`-1` 表示不限 |
| 备注 | `无` | 自由填写 |

### 4.2 运行模式：脚本直控（本视频选择）

**运行模式** 下拉框有两个选项，本视频选择 **脚本直控**。选择后页面出现三条提示：

> ⚠ 脚本直控不会读取该用户的账号、体力副本和 MAS 任务开关。
>
> ℹ 请先在 SRA / 三月七助手中完成原生配置，再一键导入；MAS 只负责启动游戏、跟踪/停止脚本进程和最终清理。
>
> 🔒 **MAS 管控配置已停用** —— 任务开关、账号、体力副本和动态选项在脚本直控模式下都不会生效。

![添加用户-脚本直控](/docs/img/video-tutorial/08-添加用户-脚本直控.jpg)

### 4.3 一键导入 M7A 配置（用户快照）

「脚本直控」小节中的 **三月七助手 CLI** 卡片：

- 右上角开关：**执行 / 跳过** —— 控制运行时是否执行这份导入的 `config.yaml` 快照；
- 点击 **一键从源配置导入** 按钮，AUTO-MAS 会读取三月七路径下的 `config.yaml`，生成用户快照。

导入成功后显示：

> ✅ **已导入用户快照**
> `C:\Users\Administrator\Desktop\March7thAssistant_full\config.yaml · 2026-09-05T07:46:59.8614...`

![用户快照导入成功](/docs/img/video-tutorial/09-用户快照导入成功.jpg)

保存后回到脚本管理，卡片下方便挂上了这个用户（含服务器、日常代理次数、剩余天数、历战余响 / 周常完成状态等标签）。

## 5. 第四步（可选）：核对 M7A 原生设置

因为「脚本直控」模式下真正干活的是 M7A 自己，所以值得打开 M7A 检查一遍原生配置。视频里从资源管理器双击 **March7th Assistant.exe**（也可以用 `March7th Launcher.exe` 启动器）打开主程序。

**「体力」页**示例（清体力相关开关，视频截取）：

## 6. 第五步：调度中心执行自动代理

### 6.1 调度中心布局

点击左侧导航 **调度中心**。页面自上而下：

- **主调度台**（带状态标签：绿=空闲 / 运行中 / 结束），右上角 **任务完成后电源操作**（视频选 `无动作`，另有＋号新建调度台）；
- 执行栏：**脚本选择器**（格式 `脚本 - 类型 - 名称`）＋ **模式**（`自动代理`）＋ 右侧蓝色 **▶ 开始执行**；
- 下方两栏：左 **任务总览**（脚本 → 用户的树，带每级 运行/完成 状态），右 **日志**（右上角 自由浏览 / 保持最新 切换）。

在脚本选择器中选择 `脚本 - HSR - 新 HSR 脚本`（下拉里会列出全部脚本及用户数）：

![调度中心-选择脚本](/docs/img/video-tutorial/15-调度中心-选择脚本.jpg)

### 6.2 开始执行

点击 **▶ 开始执行**，弹出绿色提示 **✅ 任务启动成功**，主调度台进入「运行」状态，执行栏变为：

> 任务：`脚本 - HSR - 新 HSR 脚本` ｜ 模式：`自动代理` ｜ 右侧出现红色 **⊘ 停止任务**

![调度中心-任务启动成功](/docs/img/video-tutorial/16-调度中心-任务启动成功.jpg)

### 6.3 启动阶段日志逐行解读

日志区会实时滚动，启动阶段的关键行（时间已打码格式 `[HH:MM:SS]`）：

```text
[15:51:32] 开始 HSR 配置检查
[15:51:32] HSR 外部脚本日志运行行捕获
```

## 9. 要点回顾与常见问题 FAQ

**Q1：脚本页的「MAS 管理游戏」和用户页的「运行模式」是什么关系？**
A：脚本页的 `MAS 管理游戏 = 是` 决定**游戏进程**由 MAS 启动/关闭/重启/监测（脚本直控时 MAS 只负责启动游戏、跟踪/停止脚本进程和最终清理）；用户页的 `运行模式` 决定**脚本任务**（账号、体力副本、任务开关）由谁管——本视频用「脚本直控」，任务行为完全跟随 M7A 的 `config.yaml` 快照。

**Q2：SRA 路径必须填吗？**
A：不必。HSR 脚本支持「三月七 / SRA 双脚本适配」，只填三月七路径即可启用三月七引擎（黄色警告只要求"至少一个"引擎路径）。

**Q3：游戏已经开着，能直接开始执行吗？**
A：能，但日志会提示 `检测到游戏已在运行，本轮不会中途修改分辨率` 并 `跳过重复启动`。若希望 MAS 亲自启动游戏并套用 1920×1080 窗口模式，先手动停止任务、关掉游戏（或停止后直接重跑），如视频 6.3 节演示。

**Q4：为什么历史记录里有两条「失败: HSR 脚本直控运行中」？**
A：因为短时间内停止又启动了任务，前两次尝试被判定为“已有直控任务在运行”。最终以状态为「完成」的那条为准即可。

**Q5：我在 M7A 里改了设置（比如货币战争策略），为什么 MAS 跑起来没变化？**
A：脚本直控模式执行的是**导入时的 config.yaml 快照**。改完 M7A 后，回到编辑 HSR 用户页再点一次 **一键从源配置导入**，看到「M7A 原生配置已导入当前用户」即可。

**Q6：「运行时设为 1920×1080 窗口模式」会不会永久改我的显示设置？**
A：不会。该选项会在启动游戏前临时修改注册表，`游戏关闭后将恢复原值`。

**Q7：想让 MAS 帮我管账号密码、体力副本计划、任务开关怎么办？**
A：把用户的「运行模式」从脚本直控改为 **MAS 管控**。注意两者互斥：脚本直控模式下这些 MAS 配置均不生效（页面会显示“MAS 管控配置已停用”）。

**Q8：「启用低性能兼容模式」是干嘛的？**
A：仅对三月七的**差分宇宙**玩法生效，映射到 M7A 配置项 `weekly_divergent_stable_mode`，低配机器可尝试开启。

**Q9：多账号怎么加？**
A：在同一个脚本卡片上多次点「添加用户」即可；自动代理会依次执行所有启用用户，日志会汇总 `已完成用户数 / 未完成用户数`。
