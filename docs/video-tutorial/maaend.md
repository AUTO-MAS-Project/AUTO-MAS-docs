# AUTO-MAS 部署 MaaEnd（明日方舟：终末地）脚本图文教程

> 本文根据 2026-09-17 的完整部署录屏 `2026-09-17 16-01-16.mp4`（96 分钟，1920×1080）逐步整理而成，覆盖从**下载安装包**到 **MaaEnd（明日方舟：终末地）脚本配置完成、游戏完成首次登录**的全流程。

> - **自动化链路**：AUTO-MAS（脚本管理 / 调度）→ MaaEnd（自动化本体）→ 终末地 PC 端（电脑端-前台控制，**无需安卓模拟器**）
> - 同一场录屏中还部署了 MAA（明日方舟）脚本，见《[AUTO-MAS 部署 MAA（明日方舟）脚本图文教程](/docs/video-tutorial/maa)》，两者互不依赖。

## 1. 准备工作

### 1.1 需要提前下载的文件

在浏览器中下载以下 2 个压缩包（本例均保存在 `E:\Badwolf\Downloads`，即资源管理器里的「下载」文件夹）：

![下载完成的压缩包](/docs/img/video-tutorial/step01-downloads.jpg)

| 文件 | 作用 | 大小（约） |
| --- | --- | --- |
| `AUTO_MAS-v5.4.0.zip` | AUTO-MAS 主程序安装包（内含 `AUTO-MAS-Setup.exe`） | 155 MB |
| `MaaEnd-v2.28.0-win-x86_64.zip` | MaaEnd 终末地脚本 | 248 MB |

> 截图中还有 `MAA-v6.17.5-win-x64.zip`，那是《MAA（明日方舟）脚本教程》使用的，部署 MaaEnd 不需要它。

### 1.2 环境前置条件

- **解压工具**：系统需能解压 `.zip`（视频中使用 WinRAR 查看压缩包，解压用的是 Windows 自带的「全部解压缩」，两者任选）。
- **《明日方舟：终末地》PC 客户端已安装**（本例安装于 `E:\Games\Arknightss Endfield`，主程序为 `Endfield.exe`）。
- **无需安卓模拟器**：MaaEnd 通过「电脑端-前台」直接控制 PC 版游戏，不依赖 MuMu 等模拟器。
- 磁盘空间：AUTO-MAS 安装至少需要 **588.8 MB** 可用空间，另为 MaaEnd 预留约 1 GB。

> 💡 目录约定：本教程将 AUTO-MAS 装到 `D:\AUTO-MAS`，MaaEnd 解压到 `D:\MAS` 下。路径中尽量不要出现中文和空格，可减少后续抓窗口类问题。

## 2. 安装 AUTO-MAS 主程序

### 2.1 解压安装包

1. 在「下载」文件夹中**右键单击** `AUTO_MAS-v5.4.0.zip`。
2. 选择 **「全部解压缩」**。
3. 目标路径保持默认（自动填为 `…\Downloads\AUTO_MAS-v5.4.0`），**单击「提取」**。
4. 解压完成后进入该文件夹，可以看到 `AUTO-MAS-Setup.exe`（约 159,699 KB）。

### 2.2 运行安装向导

**双击** `AUTO-MAS-Setup.exe`：

![双击运行 AUTO-MAS-Setup.exe](/docs/img/video-tutorial/step03-run-setup.jpg)

1. **选择安装语言**：保持「简体中文」，**单击「确定」**。

    ![选择安装语言](/docs/img/video-tutorial/step04-language.jpg)

2. **许可协议**：阅读 GNU AGPLv3 协议，**点选「我同意此协议」**，然后单击「下一步」。

    ![同意许可协议](/docs/img/video-tutorial/step05-license.jpg)

3. **选择目标位置**：默认是 `C:\Program Files\AUTO-MAS`。本例通过「浏览」改为 **`D:\AUTO-MAS`**（也可以直接在输入框中改），**单击「下一步」**。

    ![修改安装路径为 D:\AUTO-MAS](/docs/img/video-tutorial/step06-installpath.jpg)

4. **正在安装**：等待安装程序解压文件（进度条走完，期间会显示 `D:\AUTO-MAS\AUTO-MAS.exe` 等文件名）。

    ![安装中](/docs/img/video-tutorial/step07-installing.jpg)

5. **安装完成**：保持勾选 **「运行 AUTO-MAS」**，**单击「完成」**。安装程序退出并自动启动 AUTO-MAS，桌面上也会生成 AUTO-MAS 快捷方式。

    ![安装完成并运行](/docs/img/video-tutorial/step08-finish.jpg)

## 4. 首次启动：自动配置运行环境

首次启动 AUTO-MAS 会弹出环境配置向导「**欢迎使用 AUTO-MAS，正在自动配置您的运行环境**」，共 6 步，全程自动，**无需任何点击**：

![环境配置向导：源码拉取中](/docs/img/video-tutorial/step09-env-clone.jpg)

| 步骤 | 内容 | 说明 |
| --- | --- | --- |
| 1 Python 安装 | 安装内置 Python | 完成后显示「Python 安装完成 / 环境已就绪」 |
| 2 Pip 安装 | 安装 pip | 自动 |
| 3 Git 安装 | 安装 Git | 自动 |
| 4 源码拉取 | 克隆 AUTO-MAS 后端源码 | 自动切换镜像源（如 gh-proxy (Cloudflare)，尝试进度 1/7） |
| 5 依赖安装 | pip 安装依赖包 | 走国内镜像（如阿里云，尝试进度 1/4），耗时最长，耐心等待 |
| 6 后端启动 | 启动后端服务 | 见下方防火墙放行 |

![源码拉取完成](/docs/img/video-tutorial/step10-env-clonedone.jpg)

![依赖安装中（阿里云镜像）](/docs/img/video-tutorial/step11-env-deps.jpg)

### 4.1 允许 Python 通过防火墙（重要）

进入「后端启动」步骤时，会弹出 **Windows 安全中心警报**：

> Windows Defender 防火墙已阻止此应用的某些功能。
> 名称：Python　路径：`D:\auto-mas\environment\python\python.exe`

**单击「允许访问(A)」**（默认已勾选「专用网络」，保持即可）：

![放行 Python 防火墙](/docs/img/video-tutorial/step12-firewall-python.jpg)

### 4.2 进入主界面

随后显示「**后端启动成功，应用已准备就绪，即将进入主界面**」，自动进入 AUTO-MAS 主页：

![后端启动成功](/docs/img/video-tutorial/step13-backend-ok.jpg)

主页左侧导航栏从上到下依次是：**主页、脚本管理、计划管理、模拟器管理、调度队列、调度中心**（底部还有游戏签到、历史记录、工具、设置）。部署 MaaEnd **不需要**配置「模拟器管理」，直接进入「脚本管理」：

![AUTO-MAS 主页](/docs/img/video-tutorial/step14-home.jpg)

## 5. 新建并配置 MaaEnd 脚本

### 5.1 新建脚本

1. **单击**左侧导航 **「脚本管理」**，再**单击右上角「+ 新建脚本」**。
2. 在弹出的「新建脚本」窗口中**点选「MaaEnd 脚本」**（MaaFramework 专项适配脚本），然后**单击「创建并配置」**。

> 脚本类型参考：通用脚本（具备日志文件的自动化脚本）、MAA 脚本（明日方舟，见 MAA 教程）、SRC 脚本（星穹铁道）、M9A 脚本（重返未来：1999）、ok-ww / ok-nte / HSR 脚本等。

### 5.2 填写 MaaEnd 脚本配置

进入「**MaaEnd脚本配置**」页面。页面顶部「重要提示」建议：*默认等待时间建议调到 60 秒*；MaaEnd 专项还在积极测试中，如有问题可加入官方 QQ 群反馈。

1. **基本信息**：

    - **脚本名称**：默认「新 MaaEnd 脚本」，可自行修改。
    - **MaaEnd 路径**：**单击「选择目录」**，定位到 MaaEnd 解压目录（本例为 `D:\MAS\MaaEnd-v2.28.0-win-x86_64`，目录内应能看到 `MaaEnd.exe` 与 `interface.json`），**单击「选择文件夹」**确认：

        ![选择 MaaEnd 目录](/docs/img/video-tutorial/step29-maaend-folder.jpg)

2. **游戏配置**：

    - **控制器**：选择「**电脑端-前台**」（PC 端终末地）。
    - **任务结束后关闭游戏**：是。
    - **游戏路径**：**单击「选择文件」**，定位到终末地安装目录（本例 `E:\Games\Arknightss Endfield`），选中 **`Endfield.exe`**，**单击「打开」**：

        ![选择 Endfield.exe](/docs/img/video-tutorial/step32-endfield-exe.jpg)

    - **启动参数**：留空。
    - **等待时间**：60 秒（启动游戏后的等待时长）。

3. **运行配置**（按需调整）：

    - 账号切换方法：改为「**MAAEND 内置账号切换**」（页面默认是 MAS 自建账号切换）；
    - 单日代理次数上限：0（不限制）；
    - 重试次数限制：3；
    - 代理超时限制（分钟）：10。

4. 保存配置。

## 6. 配置 MaaEnd 本体

### 6.1 放行 SmartScreen

首次运行 `MaaEnd.exe` 时，Windows 可能弹出蓝色提示「**Windows 已保护你的电脑**」（Microsoft Defender SmartScreen 阻止了无法识别的应用启动）。**单击「更多信息」**，再**单击「仍要运行」**：

![SmartScreen 放行](/docs/img/video-tutorial/step30-smartscreen.jpg)

### 6.2 在 MaaEnd 界面确认任务

AUTO-MAS 的「配置 MaaEnd」会启动 MaaEnd 图形界面（标题 `MaaEnd v2.28.0`，并自动建立名为 `AUTO-MAS` 的配置档案）：

![MaaEnd 主界面](/docs/img/video-tutorial/step31-maaend-gui.jpg)

- 左侧为任务列表（**全部日常 / 快速日常 / 实时辅助**）：按需勾选「拜访好友」「基建任务」等日常任务，可展开细项（如基建的「开启线索交流」、商店购买上限、种植目标「指定材料」等）：

    ![MaaEnd 任务细项](/docs/img/video-tutorial/step33-maaend-tasks.jpg)

- 右侧「连接设置」确认：**控制器＝电脑端-前台**，资源选择「通用资源（目前仅简中支持较好）」。
- 底部的「开始任务」按钮同样**不需要点**——执行由 AUTO-MAS 调度。
- 检查完毕后**单击右上角 × 关闭 MaaEnd 窗口**，回到 AUTO-MAS **单击「保存配置」**解除页面锁定：

    ![关闭 MaaEnd 窗口](/docs/img/video-tutorial/step31b-maaend-gui-close.jpg)

## 7. 添加 MaaEnd 用户

1. 在「MaaEnd 脚本」卡片上**单击「添加用户」**：

    ![MaaEnd 用户编辑页](/docs/img/video-tutorial/step34-maaend-user.jpg)

2. **基本信息**：

    - **用户名称**：自定义；
    - **账号ID**：填该账号可识别的唯一片段（本例为手机号片段 `156****2619` 的形式）；
    - **启用状态**：是；
    - **配置文件来源**：脚本（使用 MaaEnd 里的「AUTO-MAS」配置档案；点「编辑脚本设定」可回改任务勾选）；
    - **接管具体任务配置**：启用；
    - **游戏资源**：官服；
    - **剩余天数**：-1（不限制）。

3. **任务配置**：确认继承的任务开关（理智作战、理智/任务＋应急理智加强剂、基建任务等）。
4. 保存。

## 8. 启动终末地，完成首次登录

MaaEnd 需要游戏处于可操作状态。首次部署时手动启动一次《明日方舟：终末地》：

1. 启动终末地客户端，出现**扫码登录**界面时，用手机端鹰角网络账号 App 扫码确认登录：

    ![终末地扫码登录](/docs/img/video-tutorial/step-login-qr.jpg)

2. 等待客户端**更新资源**并进入标题界面、完成新手引导，到达可自由行动的状态；
3. 之后即可退出游戏（保持账号登录态），日常交给调度执行。

> 💡 首次登录与资源更新耗时较长（视频中约 12 分钟），属于正常现象；这一步只需做一次。

## 9. 调度执行日常

1. **单击**左侧导航 **「调度中心」**。
2. 在「主调度台」的任务下拉中选择 MaaEnd 脚本任务，模式保持 **自动代理**，**单击「开始执行」**（下图为调度中心的执行入口，图中选中的是 MAA 任务，MaaEnd 同理在下拉中选择）：

    ![调度中心开始执行](/docs/img/video-tutorial/step35-start-exec.jpg)

3. 执行时 AUTO-MAS 会按第 5 节的配置**自动拉起终末地**（等待时间 60 秒），交由 MaaEnd 以「电脑端-前台」控制执行勾选的日常任务；任务结束后按配置自动关闭游戏。
4. 「调度队列」的定时表（每天 00:00）到点后也会自动执行队列内任务，无需人工干预。

## 10. 日常使用与定时调度

- **手动执行**：调度中心 → 选择 MaaEnd 任务 → **「开始执行」**；右上角可设置「任务完成后电源操作」（无动作 / 关机 / 休眠）。
- **定时执行**：由「调度队列」里的定时表驱动，到点自动执行。
- **运行观察**：调度中心右侧「日志」实时滚动执行日志，可勾选「保持最新」自动跟随；「历史记录」可回溯每次执行结果。
- **修改任务内容**：MaaEnd 的日常任务勾选在 MaaEnd 界面（全部日常 / 快速日常）；用户选「接管具体任务配置」时以用户配置为准。

## 11. 常见问题与注意事项

| 现象 | 处理 |
| --- | --- |
| 「Windows 已保护你的电脑」（SmartScreen） | MaaEnd 等开源工具常见。单击「更多信息 → 仍要运行」 |
| 防火墙弹窗（Python） | 单击「允许访问」；MaaEnd 部署过程一般出现 1 次（无需 adb） |
| 提示「MaaEnd 文件不完整，请卸载后重新安装 MaaEnd」 | 确认 MaaEnd 路径选择的是**包含 MaaEnd.exe 和 interface.json 的那一层目录**；若解压不完整，删除后重新解压再选 |
| MaaEnd 无法连接游戏窗口 | 确认终末地客户端已启动并登录到可操作界面；控制器为「电脑端-前台」；首次部署建议先手动启动一次游戏完成扫码登录 |
| 游戏路径报错 | 游戏路径必须指到 **`Endfield.exe`** 本体（用「选择文件」而不是选目录） |
| 账号切换不生效 | 运行配置中把「账号切换方法」改为「MAAEND 内置账号切换」；账号ID 填账号唯一片段 |
| 启动游戏后脚本没动作 | 调大「等待时间」（官方建议 60 秒），给游戏留足启动加载时间 |
