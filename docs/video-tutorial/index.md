# 视频图文教程

所有截图均取自实际操作，**红圈 / 红框标注的是该步骤中鼠标点击的位置**。

> ℹ️ **版本说明**：AUTO-MAS `v5.5.0` 起界面有较大调整（环境配置向导改为 4 步、
> MAA 任务配置内联到脚本配置、MaaEnd 改由 MFW 项目引导接入等）。
> **若你使用的界面与教程不符，请以 v5.5 版教程为准。**

## 教程选择建议

- **明日方舟（安卓模拟器）**：新版用户直接看 [v5.5 MAA 部署](/docs/video-tutorial/maa-v55)；仍在 v5.4.x 的用户看 [v5.4 MAA 部署](/docs/video-tutorial/maa)；
- **终末地（PC 端）**：v5.5 起通过 [MFW 项目引导](/docs/video-tutorial/maaend-v55)接入；v5.4.x 用户看 [v5.4 MaaEnd 部署](/docs/video-tutorial/maaend)；
- **崩坏：星穹铁道**：参考 [M7A 接入教程](/docs/video-tutorial/m7a)（使用 HSR 脚本类型）。
