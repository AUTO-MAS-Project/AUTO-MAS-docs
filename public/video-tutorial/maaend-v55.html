AUTO-MAS-Lite v5.5 接入 MaaEnd（MFW 项目引导）图文教程

本文根据 2026-09-20 的完整部署录屏 2026-09-20 22-19-54.mp4（74 分钟，1920×1080）逐步整理而成，覆盖在 AUTO-MAS-Lite v5.5.0-beta.6 中通过全新的 MFW 项目引导 接入 MaaEnd（明日方舟：终末地）脚本、完成用户任务配置的全流程。 所有截图均取自实际部署过程，红圈 / 红框标注的就是该步骤中鼠标点击（或双击）的位置。

  • 软件版本：AUTO-MAS-Lite v5.5.0-beta.6，MaaEnd v2.29.0
  • v5.5 的重大变化：MaaEnd 等所有基于 MaaFramework 的脚本，现在统一通过 「MFW 脚本」类型 + 项目引导向导接入——向导读取项目里的 interface.json，自动识别任务 / 预设 / 控制器，并把任务配置全部内联到 AUTO-MAS 中（任务队列、自动采集、优先售卖等都在 AUTO-MAS 里编辑，MaaEnd 原生 GUI 不再是必需的）。
  • AUTO-MAS-Lite 的获取与安装、环境配置向导与《AUTO-MAS-Lite v5.5 部署 MAA（明日方舟）脚本图文教程》相同，本文简述；MaaEnd 无需安卓模拟器。

总流程一览：安装 AUTO-MAS-Lite（前置）→ 解压 MaaEnd → MFW 项目引导接入（4 步）→ 添加用户并配置任务队列 / 自动采集 / 优先售卖 → 调度队列 → 启动终末地完成首次登录。

1. 准备工作

  1. AUTO-MAS-Lite v5.5.0-beta.6 已安装（获取与安装步骤见《AUTO-MAS-Lite v5.5 部署 MAA（明日方舟）脚本图文教程》第 1–3 节；安装完成页勾选「运行 AUTO-MAS」）：

  1. MaaEnd v2.29.0 已解压到 D:\MAS\MaaEnd（目录内含 MaaEnd.exe 与 interface.json）；
  2. 《明日方舟：终末地》PC 客户端已安装（本例 E:\Games\Arknightss Endfield\Endfield.exe）；
  3. MaaEnd 走「电脑端-前台」直接控制 PC 游戏，无需安卓模拟器。

2. 安装 AUTO-MAS-Lite（前置）

首次启动 AUTO-MAS-Lite 会进入环境配置向导（镜像测速 → 运行环境 → 程序文件 → 依赖（下载约 136 MB 锁定依赖，耗时最长）→ 启动），全程自动：

完成后进入主界面。防火墙弹出「Python」警报时单击「允许访问」。

3. 通过 MFW 项目引导接入 MaaEnd

3.1 新建 MFW 脚本

单击「脚本管理」→「+ 新建脚本」→ 在类型列表中点选「MFW 脚本」（运行任何带 interface.json 的 MaaFramework 项目）→ 单击「创建并配置」。

3.2 引导步骤 1：基本信息

  1. 脚本名称：默认「新 MFW 脚本」，可自行修改；
  2. 本地项目目录：单击「选择本地目录」，定位到 D:\MAS\MaaEnd；
  3. 单击「读取 interface」——向导自动识别出 MaaEnd v2.29.0 · MaaEnd 终末地小助手，绝赞开发中!，并统计出 45 任务、3 预设、9 控制器、1 资源、65 导入、2 Agent；
  4. 底部提示「正在安装 MaaFW Runner 依赖」，等待安装完成；
  5. 单击「下一步」。

3.3 引导步骤 2：控制配置

按需选择控制器（本例后续在运行配置中使用「电脑端-前台」），单击「下一步」。

3.4 引导步骤 3：项目更新

  • 自动更新：不更新 / 运行前 / 运行后（本例选「运行前」）；
  • 更新源：Mirror 酱（需在下方填入 MirrorChyan CDK；也可留空仅用手动更新）；
  • 更新通道：稳定版；
  • 页面同时展示项目信息：当前版本 v2.29.0、GitHub 仓库、MirrorChyan RID＝MaaEnd、多平台＝是；
  • 需要立即检查时单击「检查更新」；然后单击「下一步」。

3.5 引导步骤 4：运行配置

完成运行参数设置后结束向导，脚本卡片出现在「脚本管理」中。

4. MFW 用户配置（任务队列 / 自动采集 / 优先售卖）

4.1 配置管理方式

在「MFW 脚本」卡片上单击「添加用户」，进入用户编辑页。顶部为 v5.5 新增的配置管理方式三选一：

  • 脚本：使用脚本本级共享配置，所有用户共用（本例选择）；
  • 用户：使用当前用户独立配置，与脚本配置隔离；
  • 直控：直接使用 MaaEnd 原有配置，由 MaaEnd GUI 维护。

「配置操作」提供 配置脚本共享 / 导入 / 编辑脚本设定 三个入口。

4.2 任务队列配置

v5.5 把 MaaEnd 的全部任务内联到了用户编辑页（「任务队列配置」，右上角可「读取 interface / 配置恢复」）：

  • 左侧任务队列：从 interface 识别出的任务（游戏设置、拜访好友、基建任务、信用点购物、转交委托、据点交易、自动囤货、购买稳定物资、环境监测……），可上下调整顺序、添加任务、套用预设模板；
  • 右侧任务配置面板：选中任务后显示其全部配置项（如「游戏设置」的 区服＝国服、游戏语言＝简体中文、显示模式＝窗口）。

4.3 自动切换账号（账号匹配）

「自动切换账号」任务的配置面板支持账号匹配方式：

  • 选择「手机号后四位（国服）」，在「目标账号后四位」填入账号唯一片段（国服 138****5678 → 填 5678，本例 2619）；
  • 执行时自动登出当前账号并切换到指定账号（国服按手机号、国际服按邮箱匹配）；
  • 提示：账号 / 密码字段仅用于本地记录，不会自动导入脚本。

4.4 自动采集配置

「自动采集配置」区块：

  • 自动采集：开启；
  • 采集安排：分散采集；
  • 四号谷地·稀有采集物：已选 5/5（路线4：纯晶多齿叶、路线5：轻露石、路线6：轻红柱状菌、路线13：中解石、路线14：晶化多齿叶）；
  • 四号谷地·一般采集物：已选 2/2（路线1：映火霜花、路线2：雷纹枝突）。

4.5 优先售卖与物品保留

「信用点购物」等任务的详情面板中还支持：

  • 仅售卖优先货品（Yes/No）；
  • 四号谷地 / 武陵优先售卖配置：按优先级 1–6 配置优先出售的物品（未配置物品按选品策略选择）；
  • 启用物品保留规则：为物品设置最低保留数量或将其排除。

保存用户。

5. 调度队列

「调度队列」页面 v5.5 新增「队列类型」（定时队列）与「延时执行」（分钟）：

  1. 单击「新队列」创建（本例建了「新队列」05:00 / 23:00 / 17:00 三条定时，以及「end」队列 04:00）：

  1. 队列参数：启动时运行＝否；定时运行＝按需；完成后操作＝无操作（或关机/休眠）；
  2. 定时列表：「添加定时」→ 设置执行周期（周一～周日）与执行时间；
  3. 任务列表：「添加任务」→ 把 MFW 脚本（MaaEnd）加入队列，保存。

6. 启动终末地，完成首次登录

与 v5.4 部署相同：首次部署手动启动一次终末地，扫码登录并等待资源更新、完成新手引导；此后即可退出游戏，由调度自动执行。

💡 首次登录与资源更新耗时较长属正常现象；这一步只需做一次。

7. 常见问题与注意事项

现象 处理
「读取 interface」识别不到任务 确认本地项目目录选择的是包含 interface.json 的 MaaEnd 根目录（D:\MAS\MaaEnd），而不是其上层或子目录
「正在安装 MaaFW Runner 依赖」耗时较长 首次接入需要下载 MaaFW 运行时，耐心等待；失败可重进向导重试
Mirror 酱更新不生效 在「项目更新」页填入有效的 MirrorChyan CDK；或改用「检查更新」手动更新（GitHub 源）
账号切换不生效 「自动切换账号」任务中账号匹配方式选「手机号后四位（国服）」并填写目标后四位；用户列表中该账号需启用
想继续用 MaaEnd 原生 GUI 配置 配置管理方式选「直控」，由 MaaEnd GUI 维护配置
「Windows 已保护你的电脑」（SmartScreen） 运行 MaaEnd.exe / AUTO-MAS 相关程序时单击「更多信息 → 仍要运行」
